# PrivacyCheck 🔐

PrivacyCheck is a simple Python-based tool that detects sensitive information in text before it is shared online.

Features
Email detection
Phone number detection
URL detection
Password pattern detection
Sensitive information masking
Privacy risk scoring
Technologies Used
Python
Regular Expressions
Streamlit
Pytest
Project Goal

To help users identify and protect personal information before sharing text publicly.

Author

Created as a Python learning project.
